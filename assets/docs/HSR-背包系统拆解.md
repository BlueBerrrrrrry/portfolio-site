## 一、设计目的（整体系统与背包系统）

### 1.1 整体系统四条目的

- **① 长线内容消耗**：版本化内容（主线/活动/新模式）锚定 6 周节奏，养成系统作为内容消化器；
- **② 分层养成深度**：角色（等级/行迹）+ 光锥 + 遗器 + 星魂四条线，深度与肝度分层；
- **③ 多循环长留**：模拟宇宙/差分宇宙（刷遗器）+ 忘却之庭/虚构叙事/末日幻影（检验）+ 常时活动（限时奖励）形成三条循环；
- **④ 商业化**：祈愿（角色/光锥池）+ 开拓力（体力）限制供给节奏 + 月卡/纪行平滑付费。

### 1.2 背包系统的定位（关键设计判断）

- 背包不是"存储"，而是**「养成循环的收纳器与决策台」**：所有游玩产出的验收、筛选、消耗都发生在这里；
- 背包上限是**「循环节奏的调节器」**：有限空间（遗器 2000→3000）迫使玩家持续做"筛选-分解-再刷"的决策，维持模拟宇宙循环的活跃度；
- 背包必须低决策成本：筛选器/锁定/一键清理，避免清理成为新的负反馈。

## 二、系统全景（玩家路径遍历）

### 2.1 主界面与入口结构

| 区块 | 内容 | 玩家作用 |
|---|---|---|
| 资源栏（右上角） | 星琼/信用点/开拓力/遗器/段位等常驻展示 | 全局状态一眼可见，限制引导（体力→模拟宇宙） |
| 手机（主入口容器） | 短信/活动/角色/商城等（红点聚合） | 信息中枢；3.3 优化红点跨设备/分类外显 |
| 列车（首页场景） | 同伴/日历/委托 | 叙事沉浸与轻任务入口 |
| 菜单入口 | 角色/光锥/遗器（背包）/任务/商店/智库/成就 | 养成玩法主操作台 |

### 2.2 养成链（背包各页签对应养成对象）

- 角色页：等级/行迹/星魂 → 副本刷材料 → 回到角色页消耗；
- 光锥页：升阶/叠影 → 光锥材料；遗器页：强化/筛选 → 模拟宇宙产出；
- 材料页：所有养成/兑换材料的集散地；消耗品页：战斗/副本道具。

### 2.3 循环闭路

> 体力 → 模拟宇宙/遗器副本 → 产出遗器 + 材料 → 背包筛选/锁定/分解 → 强化主C → 忘却之庭等验证 → 提升星琼抽卡 → 新角色 → 再来一圈。**背包处在"产出→消耗"的咽喉位。**

## 三、功能详情：背包系统（深挖）

### 3.1 入口与主界面

- 入口：主菜单「背包」/手机入口；各页签顶部展示持有数量与上限（如 遗器 2,342/3,000）；
- 页签结构（实测口径，随版本调整）：角色 / 光锥 / 遗器 / 材料 / 消耗品 / 其他（任务、贵重物等）；
- 每页支持：列表/网格视图、排序（品质/等级/获取时间/稀有度）、名称搜索、批量选择。

### 3.2 遗器页（本拆解重点）

| 功能 | 规则细节（可执行） | 来源/置信度 |
|---|---|---|
| 获取展示 | 外圈4件+内圈2件套装结构；部位：头/手/衣/鞋+球/绳 | 高（公开常识） |
| 主词条 | 每件唯一主词条（头=固定生命、手=固定攻击；衣/鞋/球/绳按池子） | 高 |
| 副词条 | 4 条随机，强化 5 级随机提升（+15 满级） | 高 |
| 筛选器 | 按套装/部位/主词条/等级组合筛选（2.0 成体系） | 中高 |
| 锁定 | 可锁定遗器，批量操作时受保护 | 高（官方优化公告） |
| 分解 | 四星=1000 经验=2 个遗失碎金（500×2）；五星=1500 经验=3 个遗失碎金（500×3）；2.0 起五星分解可选返还碎金；每次分解可批量、可选全选 | 高（17173/2.0） |
| 上限 | 公测约 1500 → 2.x 2000 → 3.3 起 3000（官方更新电台） | 高 |
| 合成 | 自塑尘脂/遂愿尘脂合成定向遗器；3.5 起遂愿合并至自塑 | 高 |

### 3.3 材料 / 消耗品 / 其他页

- 材料页：堆叠上限（常见 9999），点击物品弹详情（获取途径/用途跳转）；
- 消耗品页：恢复/战斗道具，支持「物品说明」与使用；贵重物/任务物品回收风险提示（不可分解或可限次分解）。

### 3.4 界面规则（规则层）

| 规则项 | 说明 | 设计价值 |
|---|---|---|
| 批量操作 | 多选 → 一键分解/强化/使用，锁定项自动跳过 | 降低清理成本 |
| 筛选组合 | 套装×部位×主词条×等级 可叠加 | 把"选择"变成"排除法"，决策变快 |
| 排序唯一 | 品质→等级→获取时间；同类再按 ID | 任何列表结果唯一，避免歧义 |
| 红点 | 新获得/可合成/上限临界的提醒；3.3 优化为查看即消 | 引导但不过载 |

## 四、规则与数值（边界情况成表）

| 边界场景 | 处理 |
|---|---|
| 遗器容量满 | 无法继续获取旧遗器 → 需清理后继续；上限提升本身是运营调节手段 |
| 分解四星/五星 | 两步确认（提示返还）；锁定品不被选中 |
| 五星分解收益 | 经验 vs 碎金二选一（2.0+）：要经验走强化，要碎金走合成 |
| 材料堆叠满 | 显示超量但可继续（溢出部分下次进入处理）或提示清理 |
| 筛选无结果 | 显示空态 + 清除筛选入口 |
| 跨版本改名/合并 | 3.5 遂愿尘脂合并 → 旧道具按比例转换，需官方换算公告 |

## 七、结论层

### 7.1 可借鉴点（5 条）

- **① 背包=养成循环的收纳器**：入口/排序/筛选/分解/锁定五种能力一体，把"消耗"做进体验而不是后台；
- **② 筛选器是最被低估的系统**：把筛选做成"排除法"，直接决定了玩家清理效率；
- **③ 分解经济闭环**：清理行为直接产出强化资源（碎金），转化负反馈为正反馈；
- **④ 上限是节奏调节器而非技术限制**：上调节奏（1500→2000→3000）本身就是运营话术与生命周期管理；
- **⑤ 锁定+批量保护组合**：让高价值物品从批量操作中安全豁免，允许"放心全选"。

### 7.2 三个坑

- ① 上限过紧会变成真实负反馈（出本失败感，需计算掉落率与清理耗时）；
- ② 筛选器能力越强，新玩家学习成本越高（需要"默认筛选方案/一键清理"兜底）；
- ③ 分解规则调整（经验→碎金二选一）会牵动既有玩家沉淀，需公告与换算透明。

### 7.3 行动项（假设接手类似系统）

- **D1** 建立"清理耗时-掉落速率"比例表，上限以此反推而不是拍脑袋；
- **D2** 提供"推荐清理方案"（按流派预设筛选，如 弃 dot/无充能绳），降低新手决策成本；
- **D3** 分解二次确认统一为"预览返还 + 锁定豁免"，避免误删；
- **D4** 版本节奏：上限松动（扩容）与玩法密集期（堆积期）错峰发布，避免同时发生。
