04

故事与演出 NARRATIVE

世界观

一座孤立海岛上的生物科技研究塔。公司在此进行生长素（Growth Serum）实验，试图培育可控的巨型植物。实验失控：楼内植物野蛮生长，整座塔被植被侵蚀。

玩家是一名受雇潜入的研究员 / 特工，目标是取得研究数据，抢在灾难扩散前把方案带出去。

叙事呈现（全部已实现）

  • 开场：黑屏白字，8 行两句话一组，10.2 秒后淡出
  • 一楼大堂：38 件植被 + 3 棵 11–15 米突变巨木，环境叙事
  • 二楼阳台：主角内心独白 + 可拾取《项目纪要·第 17 次观测》
  • 三楼楼梯口：队友无线电 + 镜头推近门
  • 取得数据：队友无线电 + 全区警报启动
  • 楼顶：转视角 → 连环 21 次爆炸 → 直升机升空 → 黑屏白字收束
撤离演出分镜
转视角看塔楼 连环 21 次爆炸 随直升机升空 黑屏白字收束

升空阶段视角保持自由——玩家可以回头看着这座塔在身后崩塌，而不是被切进过场。

05

设计总览 OVERVIEW

核心机制

观察 → 选路 → 诱敌 → 暗杀。守卫有贴地可视化的视野扇形；玩家可绕后、贴墙、蹲进通风管，或用投掷物把守卫引开。

观察→选路→诱敌→暗杀

空间动线

屋顶起点 → 一楼大堂（密林走廊）→ 电梯 / 楼梯竖井 → 二楼办公区 → 29 层档案室 → 全区警戒 → 楼顶停机坪。垂直交通贯穿全塔。

情绪曲线

潜入的克制 → 教学区建立信心 → 档案室小 BOSS 的压迫 → 取物后警报爆发 → 楼顶爆炸峰值 → 黑屏余韵。

机制递进

先让玩家「看见」守卫的视野，再教「蹲伏与绕行」，然后给「投掷诱敌」，最后要求「组合使用」——每一层只加一个变量。

观察→蹲伏→诱敌→组合

L0

序章 · 屋顶与大堂 PROLOGUE

入场机制

玩家在屋顶出生，可俯瞰整座塔。开场以黑屏白字交代任务与动机（8 行、10.2 秒后淡出），随后进入一楼大堂——巨树从中庭长出，直接暗示“野蛮生长”。

设计亮点

  • 用环境讲故事：38 件植被 + 3 棵 11–15 米突变巨木，不靠台词交代失控
  • 先给全景，再收窄视线：屋顶俯瞰建立空间感，大堂走廊把视线收回，引导玩家走向电梯
  • 开场克制：只给文字与氛围，不急着教操作

L1

第一关 · 二楼办公区 LEVEL 1

流线
进入办公区 拾取 / 投掷 / 暗杀教学 通风管与绕行 阳台笔记

教学区用提示牌逐个引入「拾取 → 投掷 → 暗杀」；通风管道只能蹲着通过，把「蹲伏」变成一次不可回避的操作。

情绪曲线

低压力、高容错：玩家在这里第一次主动「制造声音」，建立「我能控制守卫」的信心。

设计亮点

  • 一个区域只教一件事：拾取、投掷、暗杀分点教学，不堆叠
  • 蹲伏不是按键，是规则：通风管只能蹲行，逼玩家记住姿态
  • 叙事埋在可交互物里：阳台纸条《项目纪要·第 17 次观测》补完生长素失控的因果

L2

第二关 · 29 层档案室 LEVEL 2

流线
楼梯口推镜 避开小 BOSS 视线 取得研究数据 全区警报

档案室内有一名小 BOSS 级敌人（黄色自发光），每 3 秒在两个朝向之间扫视——玩家必须在扫视的间隙里移动。

情绪曲线

全流程压力最高的一段：视野被扫视节奏切碎，容错空间最小。

设计亮点

  • 用节奏制造压力：3 秒一次的扫视，把「等待时机」变成可读的节拍
  • 颜色即危险等级：红=普通、紫=高危、黄=小 BOSS，玩家不用读字就能判断
  • 取物即转折：拿到数据的同时触发全区警报，把「潜入」切成「撤离」

L3

第三关 · 楼顶撤离 LEVEL 3

流线
逃离塔内 楼顶连廊 连环爆炸 直升机升空

撤离阶段沿线触发连环爆炸；升空时视角保持自由，玩家可以回头看着整座塔崩塌。

情绪曲线

从「逃命」的紧张一路推到爆炸的峰值，最后用黑屏白字收束。

设计亮点

  • 演出与操作同频：爆炸沿玩家路径依次触发，不是播片
  • 不夺走控制权：升空阶段视角自由，情绪由玩家自己看出来
  • 收束留白：黑屏白字「不知道能不能赶得上阻止这场灾难」，把结局交给玩家想象

06

技术与现状 TECH & STATUS

C++ 主导

任务流程、交互、AI 感知、演出与 HUD 全部由一个 Director 类驱动。

标签驱动

门、梯子、敌人、可读物、道具全部用 Actor Tag 识别，改布局不需要改代码。

自写演出序列

基于「状态 + 时间」的序列（不依赖 Sequencer），可精确控制镜头融合、锁移动、黑屏与爆炸节奏。

Canvas HUD

直接绘制文字与色块，无 UMG 资产；改字号只需改数字。

白盒方法论

全部几何体为引擎基础形体与方块：灰色为主，青色=可交互、红色=危险、金色=关键道具、绿色=植被。先用白盒验证空间、节奏与信息可读性，再谈美术。

已知限制（如实呈现）

  • 敌人没有寻路（无 NavMesh），追击为直线移动，会被墙卡住
  • 敌人为静态网格拼装，没有骨骼与走路动画
  • 敌人当前不主动追击（功能已实现，按需求关闭）
  • 阅读卡背景是「压暗」而非真正模糊（Canvas 无法模糊）
  • 投掷 / 蹲伏 / F 键部分逻辑尚未经过真人完整验证
